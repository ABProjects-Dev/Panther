# Roadmap

1. **Repository and project foundation:** Gradle, app entry point, dependencies and documentation.
2. **Design system and application navigation (in progress):** reusable components and four-destination shell implemented; verify accessibility, RTL and visual refinement.
3. **Room database and domain models (in progress):** version 1 schema and transactional repositories implemented; run tests, generate and commit schema, and add migrations for future changes.
4. **User profile (in progress):** local editing and Photo Picker implemented; verify persistence, validation and image handling on devices.
5. **Workout program management (in progress):** create, rename, delete with confirmation, activate, deactivate and archive implemented; verify behavior.
6. **Training days and exercise editor:** reorder days and exercises; independent per-set repetition or duration targets.
7. **Dashboard (in progress):** active program summary, recent programs and quick creation implemented; verify behavior.
8. **History and archive (in progress):** program history and archive actions implemented; verify behavior.
9. **Settings and theme management (in progress):** DataStore-backed dark, light and system selection implemented; verify on devices.
10. **JSON backup and restore:** Storage Access Framework, full validation, confirmation and atomic restoration.
11. **PDF export:** export programs to a user-selected location.
12. **Testing, optimization and release:** expand unit, database and UI coverage, accessibility, localization and release preparation.

Each phase should include relevant tests, migrations where applicable, and documentation updates. This is an ordering guide, not a claim that future phases are implemented.
