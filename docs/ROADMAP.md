# Roadmap

1. **Repository and project foundation:** Gradle, app entry point, dependencies and documentation.
2. **Design system and application navigation:** refine reusable components and implement the four destinations as real features arrive.
3. **Room database and domain models:** normalized schema, repositories, migrations and transactional activation rules.
4. **User profile:** local profile editing and Android Photo Picker.
5. **Workout program management:** create, edit, delete with confirmation, activate and deactivate.
6. **Training days and exercise editor:** reorder days and exercises; independent per-set repetition or duration targets.
7. **Dashboard:** active program summary, recent programs and quick creation access.
8. **History and archive:** distinguish and manage previous and archived programs.
9. **Settings and theme management:** persisted preferences and light/dark selection.
10. **JSON backup and restore:** Storage Access Framework, full validation, confirmation and atomic restoration.
11. **PDF export:** export programs to a user-selected location.
12. **Testing, optimization and release:** expand unit, database and UI coverage, accessibility, localization and release preparation.

Each phase should include relevant tests, migrations where applicable, and documentation updates. This is an ordering guide, not a claim that future phases are implemented.
